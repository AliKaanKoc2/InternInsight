# InternInsight

InternInsight is a mobile application designed for Sabancı University students to share and explore internship experiences at companies, research institutions, and universities.

## Project Overview

InternInsight aims to help students make more informed decisions about internship opportunities by providing access to experiences shared by previous interns.

## Core Features

- **User Accounts:** Registration, login, and basic user profiles.
- **Internship Experiences:** Browse, share, edit, and delete internship experiences.
- **Search and Filtering:** Find relevant experiences by location, organization, and internship role.
- **Internship Verification:** Manual verification of internship completion by project administrators before posting.

## Technologies

- **Frontend:** Flutter & Dart
- **Backend:** Python REST API
- **Database:** MySQL
